## 🆘 If Something Goes Wrong

### Problem: Script won't run
**Solution:** Check READ_ME_FIRST.md or START_UNI_HUB.md troubleshooting section

### Problem: Database connection error
**Solution:**
- SQLite runs as an embedded database — no separate server needed
- Ensure the backend has write permissions to create the .db file

### Problem: Port already in use
**Solution:** 
```bash
lsof -ti:5000 | xargs kill -9  # For port 5000
lsof -ti:8000 | xargs kill -9  # For port 8000
```

### Problem: Frontend shows blank
**Solution:**
- Hard refresh: Ctrl+Shift+R (Cmd+Shift+R on Mac)
- Clear browser cache

### Problem: API returns 404
**Solution:**
- Check backend is running: `curl http://localhost:5000/api/health`
- Restart backend server

**Still stuck?** See START_UNI_HUB.md "Troubleshooting" section
